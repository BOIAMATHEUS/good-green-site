Pop-ups sob demanda. Qualquer página do site abre um modal direto com ?abrir=: roleta, carrinho, busca, entrar, lista ou boas-vindas. No quiz, ?abrir=kit.
A roleta lembra quem já girou. Pelo link do hub ela sempre abre; navegando normalmente, só aparece para quem ainda não girou (para testar de novo, use uma janela anônima).
Preços, prêmios e depoimentos são de protótipo. Nada aqui é a loja oficial.
